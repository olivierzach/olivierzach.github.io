Projects, papers, and notes tend to scatter across repos and private scratchpads. This site pulls the public parts into one place.

The useful pages should answer three questions: what problem is this about, what was built, and where the code or reference lives.

Some projects are finished. Some are active. Some are just a clean experiment scaffold.

That is fine. A thin page is still useful if it points to the repo and the question.
